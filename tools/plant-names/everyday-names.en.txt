# English everyday names added by hand, one plant to a line:
#
#   Genus: Name, Name
#   Genus species: Name, Name
#   Genus species 'Cultivar': Name
#
# The first name is the one the app shows next to the botanical name, so put the one people use
# first. The others only help find the plant. These come before Wikidata's, which has a name for many
# species but often not the one on the label in a shop. Write them the way they are shown: a capital
# at the start and on proper names only.
#
# An old botanical name is fine, it lands on the name the plant goes by now. The build warns about a
# genus or species it doesn't know, which catches typos.
#
# A line starting with - lists names from Wikidata to leave out, when one is wrong or misleading:
#
#   - Genus species: Name

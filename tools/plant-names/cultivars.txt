# Cultivars and trade names added by hand, one per line:
#
#   Genus species 'Cultivar'
#   Genus 'Cultivar'
#
# Leave the species out for hybrids and for names the trade doesn't agree on. A name here wins
# over the same one from Wikidata. Some of these, like 'Albo Variegata', aren't valid cultivar
# names under the rules for naming cultivated plants, but they are what's on the label, so they
# are what people type.
#
# The build prints a warning for a genus that isn't included or a species that isn't an
# accepted one, which catches typos.

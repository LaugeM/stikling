h264-mp4-encoder 1.0.12 (MIT), `embuild/dist/h264-mp4-encoder.web.js` from the npm package `h264-mp4-encoder`, with the trailing source map comment removed since the map isn't shipped. It writes the time-lapse video in browsers without WebCodecs, like Firefox on Android. It bundles the public domain minih264 encoder and libmp4v2 (MPL 1.1, source at https://github.com/sergiomb2/libmp4v2). Loaded by `js/timelapse.js` only when needed.
